Documentación de miniSQL

Compilador SQL educativo con sintaxis en español desarrollado en Python.

Introducción

miniSQL es un compilador educativo inspirado en MySQL que permite ejecutar instrucciones SQL utilizando comandos escritos en español. Su objetivo principal es facilitar el aprendizaje y uso de bases de datos para usuarios principiantes.

El sistema analiza, valida y traduce instrucciones escritas en miniSQL hacia consultas SQL compatibles con MySQL. Además, cuenta con una interfaz gráfica desarrollada en Python mediante la librería CustomTkinter.

El compilador incluye distintas etapas del proceso de compilación: análisis léxico, sintáctico y semántico, generación del árbol sintáctico, traducción a SQL estándar y ejecución de consultas sobre MySQL.

Interfaz del sistema

La aplicación cuenta con una interfaz gráfica organizada en distintos paneles que permiten visualizar cada etapa del compilador de manera clara y ordenada.

  • Editor de código miniSQL.
  • Panel de análisis léxico.
  • Panel de análisis sintáctico.
  • Panel de análisis semántico.
  • Visualización del árbol sintáctico.
  • Panel de traducción SQL.
  • Consola de ejecución y errores.

También permite cargar archivos, escribir consultas manualmente y ejecutar el análisis completo desde la interfaz.

Módulos principales

lexer.py

Realiza el análisis léxico y genera los tokens del lenguaje.

parser.py

Valida la gramática de miniSQL y construye el árbol sintáctico.

semantico.py

Comprueba la coherencia lógica y semántica de las consultas.

traductor.py

Convierte instrucciones miniSQL a SQL estándar compatible con MySQL.

conexion.py

Gestiona la conexión y ejecución de consultas en MySQL.

utils_arbol.py

Genera la representación visual del árbol sintáctico.

Resaltado de sintaxis

El sistema incluye resaltado de sintaxis para facilitar la lectura y detección de errores dentro del editor de código.

  • Palabras reservadas → Cian
  • Operadores → Naranja
  • Símbolos → Amarillo
  • Identificadores → Blanco
  • Números enteros → Verde claro
  • Números flotantes → Verde
  • Cadenas de texto → Coral
  • Errores léxicos → Rojo

Etapas del compilador

Análisis Léxico

Convierte el código fuente en tokens reconocibles por el compilador, identificando palabras reservadas, operadores, símbolos, números y cadenas de texto.

Análisis Sintáctico

Verifica que las instrucciones sigan correctamente la gramática definida para miniSQL y genera el árbol sintáctico correspondiente.

Análisis Semántico

Comprueba la coherencia lógica de las consultas, validando tablas, columnas, tipos de datos y condiciones utilizadas.

Traducción SQL

Transforma las instrucciones escritas en español a consultas SQL estándar compatibles con MySQL.

Ejecución

Ejecuta las consultas generadas sobre MySQL y muestra los resultados obtenidos dentro de la interfaz.
